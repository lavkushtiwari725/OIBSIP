# Number Guessing Game

## Task
Oasis Infobyte SIP - Java Development
Task 2: Number Guessing Game

## Description
A console-based Java Number Guessing Game where the computer generates
a random number and the user tries to guess it.

## Features
- Random number generation
- Easy, Medium and Hard difficulty levels
- Too High and Too Low hints
- Attempt counter
- Maximum attempt limit
- You Lost message
- Play Again option
- Multiple rounds

## Difficulty Levels
- Easy: 1-50, 10 attempts
- Medium: 1-100, 7 attempts
- Hard: 1-200, 5 attempts

## Technologies Used
- Java
- Random
- Scanner
- Loops
- If-else statements

## How to Run

Compile:
javac NumberGuessing.java

Run:
java NumberGuessing
