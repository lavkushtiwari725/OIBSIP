# ATM Interface

## OASIS INFOBYTE - Java Development Internship

### Task 3: ATM Interface

A console-based ATM Interface developed using Java and Object-Oriented Programming.

## Features

- User ID and PIN authentication
- Maximum 3 incorrect login attempts
- Transaction History
- Withdraw money
- Deposit money
- Transfer money
- Balance validation
- Insufficient Funds handling
- Quit option

## Technologies Used

- Java
- Object-Oriented Programming
- ArrayList
- Scanner

## Required Classes

- Account
- Transaction
- Bank
- ATM
- Main

## How to Run

Open Command Prompt and navigate to the src folder:

cd /d D:\OIBSIP\ATMInterface\src

Compile the Java files:

javac *.java

Run the application:

java Main
